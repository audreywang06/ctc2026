Mario Markets
Before race 1: in examples\mario-live.json, replace the four names in "humans" with the four human-controlled racers.
After each race: add the humans’ overall places (1–12) to "results", one entry per race:
"results": [
  {"Daisy": 2, "Peach": 7, "Birdo": 11, "Yoshi": 4},
  {"Daisy": 1, "Peach": 9, "Birdo": 6, "Yoshi": 3}
]
Get fair values:
cornell-bots-rs.exe mario --input examples\mario-live.json --table

How to use it before race 1: these are fair prices when nothing is known yet. If a race-winner contract is offered at 18, it’s cheap by 7 points: buy. If someone bids 32, sell. For the scores, compare the book with 39.7, 30.8 and 70.5. Anything within 3 points (min_edge) isn’t worth trading.

After each race, add the four places to "results" and rerun. The numbers then move apart as skill shows, as in the two-race example.
